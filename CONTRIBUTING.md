# Contributing

Thanks for your interest! @kidcash/ui ships a small, polished set of components — we don't aim for parity with mantine/chakra. Our scope is "playful, kid-friendly, finance-flavored UI."

## What we accept
- Bug fixes
- Accessibility improvements
- Doc improvements
- New examples / recipes (Phase B+)

## What we don't accept
- New top-level components (the catalog is intentionally small; we'll grow it deliberately)
- Breaking changes to existing APIs without an issue first

## Development

```bash
pnpm install
pnpm dev      # docs site at localhost:3000
pnpm test     # run package tests
pnpm build    # build everything
```
