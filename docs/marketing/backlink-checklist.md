# @kidcash/ui — backlink + listing checklist

A living list of where the kit has been submitted, where it's been accepted, and what's still queued. Goal of this work is durable backlinks from high-authority dev domains pointing at `kit.kidcashapp.com` (which subdomain-flows authority back to `kidcashapp.com`).

## Skipped (with reason)

| List | Reason |
|---|---|
